# **Инструкция по использованию программы для менеджера**

**Назначение программы:** автоматизация расчёта предварительной себестоимости заказа на пошив изделий, определение необходимого количества материала, сроков изготовления и формирование коммерческого предложения для заказчика.

## **1. Авторизация в программе**

1. Откройте программу.
2. Введите свой логин и пароль.
3. Нажмите кнопку «Войти».
4. После успешной авторизации откроется рабочая страница калькулятора.

## **2. Выбор заказчика и параметров изделия**

1. Выберите подрядчика, для которого необходимо сформировать заказ.
2. Выберите тип изделия (например, футболка, худи и т. д.).
3. Укажите количество изделий в партии.
4. Выберите сложность пошива:
   - Простая.
   - Средняя.
   - Сложная.

## **3. Указание особенностей изделия**

Если изделие имеет дополнительные конструктивные особенности, отметьте соответствующие пункты:

- Карман.
- Капюшон.
- Подкладка.

Если дополнительных особенностей нет, оставьте эти пункты без отметки.

## **4. Выбор брендирования**

Если заказ предполагает нанесение логотипа или другого изображения, выберите необходимый способ брендирования:

- Шелкография.
- Термотрансфер.
- Вышивка.

Если брендирование не требуется, пропустите этот этап.

## **5. Указание параметров раскроя**

Заполните параметры, необходимые для расчёта расхода материала и стоимости раскроя:

| Параметр            | Что необходимо указать                                  |
| ------------------- | ------------------------------------------------------- |
| Ткань               | Выбрать используемый тип ткани                          |
| Ширина рулона       | Ширина рулона ткани                                     |
| Цена за м²          | Стоимость одного квадратного метра ткани                |
| Припуски на швы     | Размер дополнительных припусков                         |
| Длина изделия       | Длина готового изделия                                  |
| Ширина по груди     | Ширина изделия по груди                                 |
| Длина рукава        | Длина рукава                                            |
| Коэффициент отходов | Процент или коэффициент дополнительных потерь материала |

После заполнения всех параметров проверьте правильность введённых данных.

## **6. Получение результатов расчёта**

После заполнения формы нажмите кнопку «Рассчитать».

Программа автоматически рассчитает предварительную стоимость изготовления партии и стоимость одного изделия.

В результатах расчёта менеджер увидит:

**1. Общую стоимость:**

- Предварительная стоимость всей партии.
- Стоимость изготовления одной единицы изделия.

**2. Детализацию затрат:**

- Материал (с учётом отходов).
- Раскрой.
- Пошив.
- Фурнитура.
- Брендирование.

**3. Дополнительную информацию:**

- Необходимое количество ткани для изготовления партии.
- Расчётный срок готовности заказа.
- Общую трудоёмкость изготовления в нормо-часах.

Например:

## **Результат расчёта заказа**

Стоимость партии

# **69 800 ₽**

Стоимость единицы

# **698 ₽**

**Детализация затрат**

| Статья расходов | Стоимость |
| --------------- | --------- |
| Материал        | 36 000 ₽  |
| Раскрой         | 5 000 ₽   |
| Пошив           | 28 800 ₽  |
| Фурнитура       | В расчёте |
| Брендирование   | В расчёте |

**Дополнительные показатели**

- Расход ткани: ≈ 12 погонных метров.
- Срок готовности: 5 рабочих дней.
- Общая трудоёмкость: 76,5 н-час.

  Числа приведены для примера оформления результата, а не являются нормативами производства.

## **7. Сохранение расчёта и формирование коммерческого предложения**

После получения результатов менеджер может:

1. Проверить рассчитанные показатели и детализацию затрат.
2. Нажать кнопку «Сохранить расчёт».
3. При необходимости сформировать коммерческое предложение на основании полученных данных.
4. Передать сформированное коммерческое предложение заказчику.

Коммерческое предложение может использоваться для согласования стоимости, сроков изготовления и условий заказа.

## **Общий алгоритм работы менеджера**

1. Авторизация в программе.
2. Выбор подрядчика.
3. Выбор изделия, указание тиража и сложности пошива.
4. Указание особенностей изделия.
5. Выбор способа брендирования.
6. Заполнение параметров ткани и раскроя.
7. Получение расчёта стоимости, расхода ткани и сроков.
8. Сохранение расчёта.
9. Формирование и передача коммерческого предложения заказчику.

**Важно:** расчёт программы является предварительным. Перед запуском заказа в производство рекомендуется проверить параметры и итоговые показатели с ответственным технологом.
