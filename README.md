## 🗄 База данных: PostgreSQL

Система спроектирована под работу с **PostgreSQL** без сторонних локальных СУБД:
1. Строка подключения настраивается в `backend/.env`:
   ```env
   DATABASE_URL=postgresql://postgres:postgres@localhost:5432/sewing_calc
   ```
2. **Zero-Setup Fallback:** если локальный сервер PostgreSQL не запущен, бэкенд автоматически запускает совместимый PostgreSQL движок с дисковой персистентностью в `backend/data/postgres_storage.json`.
3. Поддерживается подключение к любому облачному PostgreSQL (Neon, Supabase, Railway, Яндекс.Облако).

## 🎯 Соответствие ТЗ
* **Модуль 1:** Ролевая модель (Менеджер / Главный технолог), реестр подрядчиков.
* **Модули 2–3:** Параметрический расчёт кроя (длина, ширина, припуски, рукав, межлекальные отходы), пошив с учётом сложности.
* **Модуль 4:** Детализированная смета из 5 статей затрат, расчёт сроков в рабочих днях.
* **Модуль 5:** Коммерческое предложение с печатью PDF, защищённой публичной ссылкой по токену и фиксацией факта просмотра.
* **Модуль 6:** Административная панель управления ставками нормо-часов и тканями.
* **Модуль 7:** Реестр расчётов с поиском и защитой от удаления (audit log).
